# AI 跑团主持 · DeepSeek

可导入 n8n 的中文 TRPG 跑团工作流。玩家通过聊天创建角色、探索场景，与 NPC 互动；AI 主持通过骰子工具进行随机判定。

## 导入与使用

1. 下载 [工作流 JSON](workflows/trpg-deepseek.json)。
2. 在 n8n 新建工作流，选择右上角菜单 **Import from File** 导入该文件。
3. 在 **DeepSeek 主持模型** 节点创建或选择 **DeepSeek API** 凭据，填写自己的 API Key。默认服务地址为 `https://api.deepseek.com`，模型为 `deepseek-flash`。
4. 保存工作流，点击编辑器中的 **Open chat**。
5. 输入「直接开始一个奇幻跑团」，或说明题材、规则和角色。

凭据需要在自己的 n8n 实例配置。本仓库不包含 API Key、凭据导出或本机凭据 ID。模型请求会消耗 DeepSeek API 额度。

## 工作流结构

```text
跑团聊天入口 → AI 跑团主持
                 ├── DeepSeek 主持模型
                 ├── 跑团会话记忆
                 └── roll_dice（随机骰子工具）
```

工作流有 5 个功能节点和 1 张使用说明便签。导入后默认未发布，使用编辑器内聊天即可测试；没有配置群聊平台或公开聊天页面。

## 功能与指令

| 指令 | 功能 |
| --- | --- |
| 直接开始一个奇幻跑团 | 创建默认角色，生成悬疑开场与可选行动 |
| /角色 | 创建或展示姓名、背景、属性、体力及装备 |
| /状态 | 展示当前场景、状态、目标和已知线索 |
| /掷骰 1d20+3 | 调用骰子工具并展示点数、修正和总和 |
| /存档 | 输出可复制的 Markdown 文本存档 |
| /读档 | 粘贴已有存档，核对后继续 |
| /重新开团 | 确认后重新建立故事设定 |

默认使用轻量奇幻 d20 房规：体力 10；力量、敏捷、意志分别分配 +2、+1、0；检定为 `1d20+修正`，常用难度为 10、15、20。这不是对官方 D&D 或 CoC 规则的完整实现；指定其他规则时，主持会先确认版本或说明房规。

骰子工具支持 `NdM±K`，例如 `1d20`、`2d6+3`、`1d100`。每次最多 50 颗骰子，每颗 2–1000 面，修正值绝对值不超过 1000。工具使用 JavaScript `Math.random()`，适合休闲游戏，不是可审计的竞技骰子服务。主持提示要求随机判定调用工具，关键有代价行动先征求玩家确认；模型遵循提示的程度仍可能变化。

## 记忆与存档

Simple Memory 按聊天会话区分，给模型提供最近 30 轮互动。它保存在 n8n 运行内存中，服务重启可能丢失，超出窗口的内容也不会完整保留。

长团请定期使用 `/存档` 并自行保存文本，在新会话使用 `/读档` 粘贴恢复。存档与读档是提示词驱动的文本功能，不是数据库持久化。不同会话不会自动共享一个多人跑团房间。
